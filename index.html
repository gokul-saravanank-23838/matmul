About this model

One Load models a whole-block load_input_tile invocation: 256 threads × four floats = 1024 floats / 4096 bytes per operand; A+B = 2048 floats / 8192 bytes. Only one operand is displayed, but both progress together. Eight-lane subgroups are addressing groups, not execution units. This serial Load → Loaded → Store → Ready teaching mode does not imply the original double-buffered kernel cannot overlap work. Mainloop arithmetic, caches, and hardware prefetching are intentionally excluded. Coordinates and addresses are simulated; no memory is dereferenced. Documentation & tests
