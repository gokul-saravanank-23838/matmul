Pipeline overview & mapping assumptions

Representative block: 128×128 outputs, 256 threads, 8 warps arranged 4×2. A K tile is 8 elements deep. All addresses are row-major FP32 in a 4096×4096 space. Block x selects output columns; block y selects output rows. Choose 512 K tiles for the full K=4096 product; shorter runs compute D = α · A[:, 0:K] · B[0:K, :], not the full product.

For thread t = 32w + lane, temporary index j: q = t + 256j. A loads (row = q≫3, k = q&7), B loads (k = q≫7, col = q&127). Warp w owns rows 32(w≫1)..+31 and columns 64(w&1)..+63. Accumulator (r,c) maps to row = 32(w≫1) + 8(lane≫3) + r, col = 64(w&1) + 8(lane&7) + c, plus block origins.

No XOR swizzle is assumed: the chat’s XOR example is not evidence of this kernel’s actual layout. Numeric inputs are deterministic: A[y,k] = ((3y+k) mod 7)−3, B[k,x] = ((k+2x) mod 5)−2. Accumulator numbers are exact integer sums here; this is not an IEEE rounding study.

Double buffering & barriers

Prologue loads global_a[4] and global_b[4], stores shared stage 0, then synchronizes the block. Two shared stages each hold A[128×8] + B[8×128] = 8 KiB. Tile t reads stage t mod 2. At step 0 it prefetches tile t+1 into the temporary registers, if one exists. At step 7 those registers commit to the alternate stage, then a barrier makes it available before switching.

warp_a[2][8] and warp_b[2][8] are a separate two-slot register ping-pong. This visualization loads step s+1 into the alternate slot before the FMA for step s, except at step 7. This is a source-order representation, not a latency-overlap claim. There is no out-of-range final prefetch. Barrier placement is a safe representative schedule pending the actual listing.

Epilogue staging & transpose-like reconstruction

After all K tiles, the mainloop storage is dead and the same union allocation becomes epilogue scratch. Each of 8 iterations selects accumulator row r = iteration. Each warp writes 32×8 words at offset 256w + 8lane + c. A barrier publishes those stores. Consumer lane loads 256w + 32j + lane, for j = 0..7, scales by α, and writes D. A second barrier prevents scratch reuse before all consumers finish.

Decode q = 32j + lane: producer lane = q≫3, producer c = q&7. This exchange changes which lane holds a value; it does not transpose the mathematical output. Neighboring consumers write neighboring columns. Scratch uses the first 8 KiB of the 16 KiB union; the other half is inactive, not an additional allocation.

PTX helpers / explicit memory operations

@p ld.global.L2::128B.u32: when the predicate is true, load one 32-bit word from a global address into a register. When false, no load occurs; the destination is not implicitly zeroed (a helper may initialize it separately). L2::128B is a cache/prefetch-size hint, not a 128-byte payload or proof of a cache hit. This app counts 4 bytes per active instruction.

ld.shared.v4.b32: load four 32-bit words from shared memory into four registers, a 16-byte payload. Each modeled 8-element operand fragment uses two such loads.

@p st.global.u32: when the predicate is true, store one 32-bit register word to global memory; otherwise perform no store. FP32 values travel as 32-bit bit patterns. The representative full tiles here are in bounds, so predicates are true. These helpers describe memory operations and predication—not instruction timing, cache behavior, or a cycle-accurate GPU simulation.
